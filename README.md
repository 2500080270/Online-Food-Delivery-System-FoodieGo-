# FoodieGo – Online Food Delivery System
## First Review Deliverables

### Rubric coverage
1. Business System & Module Identification
   - User module: registration, login, restaurants/menu/order/profile access.
   - Admin module: user, restaurant, order, report and system-management access.
   - User access is limited; Admin has full access.
2. UI Template & Layout – CSS Grid/Flexbox
   - Responsive CSS Grid for modules/stats.
   - Flexbox for navigation, buttons, hero points and form controls.
   - HTML + CSS + JavaScript integration.
3. Login & Signup using Local Storage
   - User registration stored in browser LocalStorage.
   - Duplicate username and duplicate mobile validation.
   - 10-digit mobile validation.
   - Password confirmation validation.
   - User authentication and Admin authentication flow.
4. Project Demonstration & Explanation
   - Demonstrate registration -> LocalStorage -> login -> user dashboard -> restricted admin control.
   - Demonstrate admin login -> full-access dashboard.
   - Use the included presentation for explanation.
5. LinkedIn Article with DTI Concepts and Review
   - Included as `LinkedIn_Article_DTI.txt` and `LinkedIn_Article_DTI.docx`.
